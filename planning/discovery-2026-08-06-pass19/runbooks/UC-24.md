# UC-24 — Global ⌘K search; notifications bell/drawer; unread badge + read sync

## Purpose

Proves **ruling 23 (R15-5)** — the ⌘K palette is REAL workspace-wide search (tasks,
branches, agents, projects) scoped to the viewer's visible projects — plus **ruling 9**
(per-user notification rows, real-timestamp DESC), **ruling 14** (ONE shared bell
popover + notification meta), **R8-3** ("waiting on you" is member-scoped), **E12**
(mark-read emits a user-scoped SSE so other tabs' badges drop), and **F18-1** (orphan
rows — deleted project — are non-clickable and excluded from the badge). Code under
test (verified 2026-08-06):

- `GET /resources/search?q=…` (`app/routes/resources.search.ts`) →
  `searchWorkspace` (`app/features/shell/command-search.server.ts:52-156`): reuses
  `listHomeProjectsForUser` (org admins see every project; members only theirs), four
  hit groups capped at 6 (`COMMAND_GROUP_LIMIT`), LIKE with `%_\` escaping, a row
  matching only on `branch` files under Branches (honest group headings).
- Palette UI: topbar BUTTON (aria-label `Search tasks, branches, agents, projects`,
  ⌘K/Ctrl+K hint — `topbar.tsx:175-191`), `use-command-palette.ts:28-34` binds
  Meta/Ctrl+K, dialog `command-palette.tsx` (listbox, Enter navigates, Escape closes).
- Bell: `top-bell.tsx` — badge = `countUnreadNotifications` (excludes unread rows whose
  project no longer exists, `notifications.server.ts:238-255`), popover header
  `N unread`/`caught up`, clicking an unread row marks it read + navigates
  (`notificationHref` — task row → task page, project row → board, org row →
  non-clickable).
- Mark-read: `POST /notifications/read` (`notifications.read.tsx`) — intents `read`
  (repeatable `id`) / `read-all`; idempotent (`changed` count); emits `notification.read`
  SSE per affected user (E12). `/notifications` page = the full drawer surface
  (URL-addressable overlay route).
- Routing prefs: `createNotification` consults `isNotifKindEnabled` (opt-out; categories
  `packets/approvals/mentions/policy/quality`) — a silenced category's row is NEVER
  written (`notifications.server.ts:54-66`).

- Non-member scoping: zero leakage of `pass19-rbac-probe` to Elif (step 3) — the same

  implementations, ruling 14).
- Pref-silenced category writes NO row (not a hidden row).

## Failure signatures (findings)

- Step 3: Elif receives any hit from the probe project → **NEW HIGH** (R15-4 leak via
  search — the exact leak `searchWorkspace`'s scoping exists to prevent).
- Badge counts rows the list can't show / includes orphaned-project rows → **F18-1
  regression, NEW MED**; header says `N unread` while list shows fewer for another
  reason → **NEW MED** (UI-14 class).
- `changed` ≠ real mutation count, or re-marking returns `changed:1` → **NEW MED**
  (idempotency, NFR16 class).
- Read-all in one tab leaves another tab's badge stale >5 s → **NEW MED** (E12).
- ⌘K opens but Enter navigates nowhere / palette shows a project the viewer can't open
  → **NEW HIGH** (R15-5 promise broken).
- Silenced mention still inserts a row (or worse, notifies) → **NEW MED** (routing
  prefs decorative).
- A notification row for a live task does nothing on click → **NEW MED** (B-FD6
  regression).
- Branches group shows a row that also matched key/title → **NEW LOW** (honest-grouping
  rule, `command-search.server.ts:117-131`).
