# UC-13 — KB create/grant reaches its grantee; reviewer inherits the deliverer's KBs (R18-1)

## Purpose

Proves the knowledge-base leg of FR9 (permitted resources) and **ruling 47 / R18-1**:

1. A KB created in org Settings and granted to a profile is INJECTED into that profile's
   run as prompt text (`buildSpecialistPersona` → `readKbBodies`,
   `app/server/tasks/specialist-run.server.ts:1272`), with the C1 honesty marker
   ("Attached resources that did NOT reach this run", :1347-1356) when a grant resolves to
   nothing. Grants reference the **directory name**, never the display name (INTENT.md §2).
2. **R18-1** — a NON-delivering (reviewer) run unions the delivering engagement's live KB
   grants into its own (`specialist-run.server.ts:787-796` fresh; `:1674-1684` resume), so a
   reviewer with `kb: []` still judges against the deliverer's conventions (F18-11 class).
3. **R19-3 boundary** — inheritance is KBs ONLY. The renamed helpers'
   docstring ("widened to SKILLS by LV-F3", :262) is aspirational; both call sites union
   `kb` alone (filed as F19-2, ruled R19-3: KB-only stands). A reviewer that reports the
   deliverer's SKILLS would be a NEW violation of that ruling.

## Failure signatures (findings)

- **Step 9 misses the canary**: read the reply for the C1 honesty admission ("the grant
  reached this run empty"). If present → the grant string does not match the store folder
  (`ls $DR/kb/`; the silent-resource / display-name-grant class) — misconfiguration, redo.
  If absent AND no marker → **NEW HIGH**: KB injection regression
  (`kb-injection.server.ts`).
- **Step 10 misses the canary but step 11 passes** → **NEW finding**: resume-leg union gap
  (`:1674-1684`; the XS-1 fresh-vs-resume parity class).
- **Steps 10 AND 11 both miss it** → **NEW HIGH**: R18-1 regression (F18-11 re-opened).
- **Step 10 reply lists the deliverer's skills** (would require granting uc13-writer a
  skill first — only probe if suspicious) → violates **R19-3**; file, cite F19-2.
- **Step 7 already knows the token** → contamination: a reviewer KB grant exists, or the
  canary leaked via an earlier run in the same store. Fix preconditions; not a product bug.
- Comment response `"triggered":false` with `runtimeDenied` → RBAC regression for an org
  admin (contracts §3.2) — **NEW**.
