## Repository summary

- **Application:** server-rendered React Router 8 / React 19 monolith written in strict
  TypeScript 7 and targeting Node.js 26 or newer.
- **Persistence:** markdown/YAML files are canonical business state; SQLite
  (`better-sqlite3`, WAL) stores application management data and derived projections.
- **Runtime:** one Node process serves SSR routes, actions, SSE live updates, and agent
  orchestration. Claude and Codex SDK adapters have a simulated fallback.
- **Organization:** `app/routes/` contains thin route modules; `app/features/` owns
  surface-specific UI and route logic; `app/server/` owns server-only services;
  `app/ui/`, `app/schemas/`, and `app/shared/` hold reusable contracts and helpers.
- **Supporting areas:** `db/migrations/` has 13 SQL migrations; `e2e/` has six
  Playwright feature specs plus setup/teardown; tests are otherwise co-located with
  implementation; `test-support/` contains fakes and harnesses.
- **Product artifacts:** `design/`, `docs/`, and `planning/` are large,
  intentionally tracked sources of UI references, architecture/operations guidance,
  build reports, and discovery records.
- **Delivery:** `Dockerfile` and `compose.yml` define the single-node deployment;
  `.github/workflows/ci.yml` runs typecheck, Vitest, and the production build.

## Dependencies and architecture notes

Primary runtime dependencies are React Router/React, Zod, better-auth,
better-sqlite3, Chokidar, YAML/frontmatter handling, Markdown rendering, and the
Anthropic Claude Agent and OpenAI Codex SDKs. Vite builds the SSR application,
Vitest covers unit/integration behavior, and Playwright covers golden-path browser
flows.

The architecture deliberately couples a local filesystem source of truth, a SQLite
projection cache, file watching, and an in-process SSE broker. This keeps deployment
simple but makes a single persistent data root and a single running node authoritative.

## Notable risks and documented gaps

- The deployment is intentionally single-node; local files, SQLite, and the in-process
  event bus do not provide horizontal scaling or active-active failover.
- Autonomous agent processes share the application/container trust boundary unless an
  operator adds worker isolation.
- The README documents no mailer, no org-level audit UI, unbounded provenance/audit
  growth, a 200-row notifications cap, incomplete MCP credential management, and a few
  deliberately stubbed or derived UI behaviors.
- Runtime data is excluded from Git, so this inventory describes the source repository,
  not a deployed instance's canonical project/task store or SQLite state.
- The repository contains extensive historical planning and generated-looking design
  reference assets; their value is intentional, but they materially increase review and
  navigation surface.
