# UC-14 — MCP server add/grant; tools reach a Claude run; Codex naming + no-auth delta

## Purpose

Proves the MCP leg of FR9 and the two DOCUMENTED backend deltas, live:

1. An org-registered stdio MCP server granted to a profile mounts into its run and its tool
   is CALLABLE (`resolveSpecialistMcpServersDetailed`,
   `app/server/tasks/specialist-mcp.server.ts:88-176`; Claude adapter passes `mcpServers`
   with `strictMcpConfig: true`, `claude-runtime.server.ts:611-615`; Codex translation
   `codexMcpServers`, `codex-runtime.server.ts:100-139`).
2. **Ruling 39 / R16-5** — MCP grants live OUTSIDE the capability matrix: the tool works
   even on a profile whose repo capabilities are all withheld (no `mcp__*` deny rule —
   that absence is the pin).
3. **Naming delta (P13-LV-15, vendor behavior, disclosed not normalized)** — the same
   declared name `uc14-echo` surfaces as `mcp__uc14-echo__echo_marker` on Claude but
   `mcp__uc14_echo__echo_marker` on Codex (the codex CLI lowercases hyphens to
   underscores; `codex-runtime.server.ts:88-95`).
4. **Credential delta (F7-MCP1 scope)** — a stored credential reaches a Claude stdio run
   as env `MCP_CREDENTIAL` but is DELIBERATELY dropped on Codex (a literal secret in
   `--config` argv would be `ps`-visible; `specialist-mcp.server.ts:39-45`,
   `codex-runtime.server.ts:105-113`).
5. Pass-19 note: on Claude, mounted MCP tools may arrive **deferred** — a pending tool
   list is NOT a failure; the run loads them via ToolSearch.

## Steps

### A. Build + register the local no-auth stdio MCP server

1. **Install the server script** (dependency-free node, newline-delimited JSON-RPC; the
   `cred:` suffix makes the credential delta directly observable). Write EXACTLY this to
   `$DR/mcp/echo-mcp.cjs`:
   ```sh
   mkdir -p "$DR/mcp" && cat > "$DR/mcp/echo-mcp.cjs" <<'EOF'
   #!/usr/bin/env node
   // uc14-echo — minimal stdio MCP server (newline-delimited JSON-RPC), no deps.
   const readline = require("node:readline");
   const rl = readline.createInterface({ input: process.stdin });
   const send = (obj) => process.stdout.write(JSON.stringify(obj) + "\n");
   rl.on("line", (line) => {
     line = line.trim();
     if (!line) return;
     let msg;
     try { msg = JSON.parse(line); } catch { return; }
     const { id, method, params } = msg;
     if (method === "initialize") {
       send({ jsonrpc: "2.0", id, result: {
         protocolVersion: (params && params.protocolVersion) || "2025-06-18",
         capabilities: { tools: {} },
         serverInfo: { name: "uc14-echo", version: "1.0.0" } } });
     } else if (method === "tools/list") {
       send({ jsonrpc: "2.0", id, result: { tools: [{
         name: "echo_marker",
         description: "Returns the pass-19 UC-14 marker plus whether MCP_CREDENTIAL reached this process.",
         inputSchema: { type: "object", properties: {}, additionalProperties: false } }] } });
     } else if (method === "tools/call") {
       const cred = process.env.MCP_CREDENTIAL ? "present" : "absent";
       send({ jsonrpc: "2.0", id, result: {
         content: [{ type: "text", text: `UC14-MCP-CANARY-4482 cred:${cred}` }],
         isError: false } });
     } else if (typeof id !== "undefined") {
       if (method === "ping") send({ jsonrpc: "2.0", id, result: {} });
       else send({ jsonrpc: "2.0", id, error: { code: -32601, message: `method not found: ${method}` } });
     } // notifications get no reply
   });
   EOF
   ```
2. **Local smoke test** (verified working 2026-08-06 — three JSON replies, last one carries
   the canary + `cred:absent`):
   ```sh
   printf '%s\n' \
     '{"jsonrpc":"2.0","id":0,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"t","version":"0"}}}' \
     '{"jsonrpc":"2.0","method":"notifications/initialized"}' \
     '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' \
     '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"echo_marker","arguments":{}}}' \
     | node "$DR/mcp/echo-mcp.cjs"
   ```
3. **Register it** (the save runs a REAL initialize→tools/list probe over stdio):
   ```sh
   curl -s -b "$CK" -H "Origin: $APP" -X POST "$APP/org/settings" \
     --data-urlencode "_csrf=$CSRF" --data-urlencode "intent=mcp-save" \
     --data-urlencode "name=uc14-echo" --data-urlencode "transport=stdio" \
     --data-urlencode "target=node $DR/mcp/echo-mcp.cjs" --data-urlencode "cred="
   ```
   Expect the response toast: **"uc14-echo saved — 1 tool discovered · spawned per run"**.
   [API] (Also visible in Settings → Resources → MCP servers with tool count 1. [UI])
