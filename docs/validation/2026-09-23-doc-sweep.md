> The second end-to-end verification of the `docs/` set, against `main` @ `7d9fbf72`
> (2026-09-23), three weeks and about 1,000 commits after the first
> ([2026-09-01-doc-validation.md](2026-09-01-doc-validation.md)). In between, rulings

> HEAD, with rulings 177–450 used as the index of what might be missing. The code won
> every disagreement. Gates run: the doc-pinning tests (`app/shared/docs/*`,

> `npm run lint && npm run typecheck && npm test`; `npm run e2e` was not run. PR #318

> merged into it: `projections-and-events.md` §§5–6 describe the run-line floor it added.

## What changed in how the set is kept

- **One header per page.** Every page's stack of dated update notes is replaced by a
  purpose sentence, a current "Source of truth" list and `Verified against main @ 7d9fbf72
  (2026-09-23)`. Each note's facts were moved into the body first. The per-ruling history
  those notes carried is in `git log -p` of each page.
- **Present tense, not correction notes.** A wrong statement is corrected in the body.
  `decisions.md` alone keeps dated notes, because a ruling's text is never rewritten
  (`development/contributing.md` §7, `README.md`).
- **`decisions.md` is in numeric order.** Rulings 118–450 had been appended at three
  points (after the unnumbered owner-decision list, and as runs 291–450, 202–290,
  191–201), so everything past 117 sat under the wrong heading. They were moved verbatim;
  every non-blank line was preserved.
- **Supersession back-pointers.** 527 sentences in rulings 118–450 cite an earlier ruling.
  Where a later ruling amended, narrowed, extended or reversed an earlier one and the
  earlier one did not say so, a dated pointer was added to the earlier block: 123 notes on
  117 rulings. `rulings-supersession.test.ts` catches only five verbs; this covered the
  rest by reading. The sharpest gaps: rulings 93, 101 and 109 still described the Codex
  read-only sandbox that ruling 185 deleted; ruling 33 was narrowed by 447, 92 amended by
  375, 131 changed by seven later rulings and 237 by five, all unmarked.

not edit them. Read against the code, they say things that are no longer true:
