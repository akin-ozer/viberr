# UC-09 — Comments: @operator / @<agent> routing; agent @tags the human back + notification

## Purpose

Proves **FR4** (comment addressing agents or teammates in ONE unified timeline, within
members-only projects per R15-4), **FR16** (conversational + typed events in a single
chronology), and the **NEW-4 convention** (an agent or operator answering a human must @tag
them AND the tag must actually notify — `notifyMentionedUsers` is wired into EVERY comment
writer). Mechanisms under test (all verified in code 2026-08-06):

- `commentToAgent` (`app/routes/project.task.tsx:320-352`, intent `comment` →
  `app/server/tasks/task-actions.server.ts:1040-1330`): records the comment via
  `appendComment` (:759 — human-mention fan-out, `task.comment` audit), resolves a
  mentioned agent (`resolveMentionedAgent`, `agent-reply.server.ts:284`), then — only for
  admin|maintainer (`hasRuntimeRole`) — resumes/starts that agent. Lower roles get the
  comment recorded, run NOT triggered, `runtimeDenied: true`.
- `@operator` → a governed operator run (`runOperator`, trigger `manual`, the comment as
  `humanComment`; task-actions.server.ts:1139-1157). `@<profileId>` (e.g. `@doc-writer`) →
  resume that agent's own session with `specialistReplyDirective` (:1003-1037), whose text
  orders: *"start your reply by tagging them — \"@<Name>\" — so they are notified"*, plus
  the P13-D-3 canonical re-anchor block.
- Reply lands via `applyAgentCompletionEffects` → `recordAgentCompletion` → the agent's
  reply comment + `notifyMentionedUsers` (NEW-4; `agent-completion-notify.server.test.ts`
  is the unit pin — this runbook is the live pin).
- Mention routing ladder (B-FD2, `mention-notify.server.ts:87-122`): exact email
  local-part → exact full display name (or dashed form) → UNIQUE first name; a tie
  notifies NOBODY and the non-delivery is disclosed on the timeline
  (`ambiguousMentionNote` for humans, `withAmbiguityDisclosure` for machine authors).
- Reserved agent handles (never a person): `agent`, `operator`, `codex`, `claude`
  (`RESERVED_HANDLES`, mention-notify.server.ts:43).
