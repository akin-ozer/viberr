# Contributing quickstart

Run these from the repository root, using Node.js 26 or newer.

## 1. Install

```sh
npm ci
```

## 2. Test

```sh
npm test
```

## 3. Typecheck

```sh
npm run typecheck
```

## 4. Dev server

```sh
npm run dev
```

Runs at http://localhost:5173. See [CONTRIBUTING.md](../CONTRIBUTING.md) for full setup.
