# UC-19 — Force-accept past a missing verdict; revision divergence surfaced (R17-1)

## Purpose

Proves three rulings on the audited admin override (`forceAcceptCompletion`,
`task-actions.server.ts:5274`; DG-2; ruling 20/R15-1):

1. **Force-accept is the only bypass for a missing verdict** — a plain accept refuses with
   the verdict-gate copy ("no approving verdict yet — run a review for a verdict, or an
   admin can force-accept", `verdictGateReason` :4707-4723); the forced path records audit
   `task.acceptance.forced` naming the **exact gate bypassed**.
2. **R17-1** — a PR head strictly AHEAD of the reviewed revision is accepted but the
   divergence is **surfaced**: the accept/force-accept confirm dialog shows the actual merge
   head + "N commits added since review"; the completion event appends the drift note
   (`revisionDriftNote` :5030-5035); the reconciler records `pr.revisionDrift`.
3. **Force never bypasses the PR-head containment gate** (`acceptancePrHeadCheck`
   :4812; A2) — a head that does not CONTAIN the delivered revision refuses even forced.

Note: a successful force-accept performs a **REAL GitHub merge** (the merge attempt runs
with `force`; only an `unmergeable` verdict is overridden into "accepted, merge pending").

## Failure signatures (findings)

- Force-accept succeeds when the PR head does NOT contain the delivered revision (step 7)
  → **NEW CRITICAL** (A2 / R15-1 gate 2 — the one gate force must never bypass).
- `pr.revisionDrift` present but NO drift note in the dialog or completion event → **NEW
  HIGH**, R17-1 regression.
- `task.acceptance.forced` missing, or `bypassed` empty/stale → **NEW HIGH** (DG-2 audit
  contract).
- Plain accept (step 1) SUCCEEDS with zero verdicts on delivered work → **NEW CRITICAL**
  (the F15-19 hole re-opened).
- Poller/manual reconcile never records `revisionDrift` for a strictly-ahead head → **NEW**
  reconciler finding (R17-1's data source dead).
- Force-accept offered while the PR is CLOSED unmerged → R16-3 violation (**NEW** — the
  control must be withdrawn, not disabled).
- Known adjacent findings — record evidence, do not re-file: UX19-2 (force-accept shown
  pre-Review beside "not at boundary" copy), F19-14 (raw state token in dialog), F19-3/F19-7
  (acceptance writers missing the confirm dialog).
