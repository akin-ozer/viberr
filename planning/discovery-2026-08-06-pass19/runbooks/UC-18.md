# UC-18 — Scheduled operator re-run (FR39): fires server-side, cancellable, terminal guard

## Purpose

Proves **FR39** — the one capability that lets an agent act with no human present:
- a maintainer+ schedules a future operator re-run; the entry is **canonical in the task
  file** (`schedules[]`), carries the backend + autonomy chosen at schedule time;
- a server-side runner fires it (`schedule.server.ts`: `startScheduleRunner` boots at
  server start, tick = 60 s, claim lease 5 min, max 3 retries; lifecycle
  `pending → claimed → fired | failed | cancelled`);
- it is **visible, cancellable, audited** (`task.schedule.created/cancelled/fired`);
- it **never fires on a terminal-stage task** (create-time refusal + runner-side
  `skipped-done` retirement) and never on an archived one (`skipped-archived`, P14-RV-03).

Known related finding (do NOT re-file): **F19-20** — a task reaching Done in the window
between the projection read and the claim can still fire (mid-tick race,
`schedule.server.ts:309`).

## Expected outcomes (PASS)

All embedded per-step above. Summary: canonical `schedules[]` entry with the exact
backend/autonomy/note; visible row; cancel leaves `firedAt: null` and prevents any run;
fire transitions pending→claimed→fired with the note reaching the operator's instruction;
Done task refuses at create time with 400.

## Failure signatures (findings)

- A cancelled schedule fires anyway → **NEW CRITICAL** (FR39 "cancellable" broken).
- Fire on a task that was Done/archived well before the tick → **NEW HIGH** (distinct from
  F19-20, which covers only the mid-tick race — check timestamps before filing).
- No fire by dueAt + 3 min → runner defect: check server stdout for "scheduled actions
  fired" / "scheduled operator re-run failed"; check `task_projections.schedules_json` is
  populated (if task.md has the entry but the projection doesn't, it's a projection bug and
  the runner is blind — **NEW HIGH**).
- `firedAt` stamped by cancel → P11-75 regression.
- Entry stuck in `claimed` > 6 min with no retry/finalize → lease-recovery defect (F10-16
  family, **NEW**).
- EK (contributor) can schedule/cancel → **NEW** RBAC finding (`run-agents` tier).
- Schedule entry lost after a board Re-scan or server restart → canonical-file violation
  (**NEW HIGH** — the file is the source of truth; rebuild must re-project it).
