# UC-26 — Org-admin override on a NON-member project: authority, honesty pill, audit (D2)

## Purpose

Proves the **D2 org-admin emergency override** (`app/server/auth/project-authority.server.ts:181-204`,
per RBAC-GOVERNANCE §1.3) and its three contracts:

1. **Authority** — an ORG admin who is NOT a project member (or is a member below tier)
   is granted project-admin-equivalent authority on that project's surfaces and governed
   mutations (`resolveProjectAuthority`; the layout loader resolves
   `myRole = "admin"` via `orgAdminOverride`, `app/routes/project.tsx:73-110`).
2. **Audit** — EVERY override-resolved GOVERNED MUTATION writes a
   `project.org_admin.override` audit row (never silent — NFR8/NFR10/FR33); plain READS
   deliberately do NOT audit (was per-page-load noise). An org admin whose own
   membership suffices writes NO override row.
3. **Honesty** — the topbar shows the risk pill `org-admin override` whose full D2
   sentence is the element's accessible name (UXA-13, `topbar.tsx:145-158`); Home shows
   every project to an org admin (`home-query.server.ts:114`) and keeps override-only
   decisions in a SEPARATE `overrideWaiting` counter, never folded into "waiting on you"
   (E6, `notifications.server.ts:132-155`).

Also re-pins the boundary: a plain org MEMBER non-member still gets the R15-4 404.

## Expected outcomes (PASS evidence)

- Non-member org admin: full read access + admin affordances + the honest pill; ZERO
  audit rows for reads.
- Each governed mutation via override → exactly one `project.org_admin.override` row
  alongside the action's own audit row; actor + project named ([API] rows at
  `<N0>+1`, `<N0>+2`).
- Same mutations under real membership → no override rows (step 5 control).
- Org member non-member: byte-identical unknown-slug 404 on GET and POST + denial row.
- Home: probe project visible to the org admin, invisible to the non-member org member.

## Failure signatures (findings)

- Governed mutation via override succeeds with **no** `project.org_admin.override` row
  → **NEW HIGH**: silent emergency authority (breaks D2's core promise, NFR10).
- Override rows written on plain page READS → **NEW MED**: the deliberate read-noise
  exemption regressed (would bury real overrides).
- Override row written in step 5 (member-suffices) → **NEW MED**: false-positive
  auditing (makes the log cry wolf).
- Pill absent (or its sentence unreachable to keyboard/AT) while acting on a
  non-member project → **NEW MED**: UXA-13 honesty regression.
- Deniz (org member) reaches the probe project, or gets a 403 instead of the 404 body
  → **NEW HIGH**: R15-4 / D2 boundary confusion.
- Home hides the probe project from the org admin → **NEW MED** (authority the UI
  cannot reach; contradicts `home-query.server.ts:114`).
- Override decisions folded into Arda's personal "waiting on you" count → **NEW MED**
  (E6 regression).
