Task pattern

The task surface should always show canonical file status, readiness, owner, branch health, latest decision packet, and a compressed typed timeline above long-form history.

Policy pattern

Policy UI separates human permissions from agent capabilities. Agents can request important events, but official state changes remain governed by product actions.

GitHub pattern

GitHub panels report execution facts: repo, branch, commits, PR, sync health, and PAT diagnostics. They never replace the canonical task file.

Responsive workspace

Desktop dense, mobile decisive.

Large screens use board, detail, and inspector panes. Narrow screens collapse to prioritized task context and sticky actions instead of shrinking the desktop board.
