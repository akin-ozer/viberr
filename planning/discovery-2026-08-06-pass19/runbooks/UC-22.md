# UC-22 — Archive task (+deleteBranch); archived drops live pills

## Purpose

Proves the **R14-3 archive contract** (`setTaskArchived`,
`task-actions.server.ts:3985-4085`) and **ruling 17**:

1. Archiving is a reversible terminal **disposition**: the file + full timeline stay; the
   task leaves the board's default view and the review queue; the open packet, pending
   recommendations AND pending schedules are withdrawn in the same write (P14-RV-03);
   audited (`task.archived` / `task.unarchived`); authority = `approve-transition`
   (maintainer+).
2. **Remote-branch deletion exists ONLY as the closed-PR recovery packet's
   `archive_task` + `deleteBranch: true` option** (ruling 17; resolved in
   `resolvePacket` :4557-4602 → `deleteTaskRemoteBranch`); the plain Archive button never
   deletes a branch.
3. **Archived drops live pills**: the task hero keeps only the stage pill (UXO-1 —
   readiness/validation suppressed, `task-main-sections.tsx:160-174`).
   KNOWN counter-findings to verify as evidence, NOT re-file: **F19-8** (board archived
   cards keep live pills + working Move controls), **F19-9** (rail Board/Review badges count
   archived tasks).
