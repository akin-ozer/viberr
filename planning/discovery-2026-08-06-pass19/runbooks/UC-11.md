# UC-11 — Second/third user; RBAC per project role; members-only invisibility (R15-4)

## Purpose

Proves **FR1/FR2/FR3** (sign-in, admin-managed membership + roles, enforced permissions,
shared visibility), **ruling 2** (project roles `admin|maintainer|contributor|viewer`,
single source `app/shared/rbac.ts` — display and enforcement render the SAME
`ACTION_ROLES` object), **ruling 25 (R15-4)** — projects are members-only: a signed-in
non-member gets the unknown-slug **404, byte-identical** on reads (layout loader,
`app/routes/project.tsx:73-77`) and on POSTs (`requireVisibleProject`,
`app/routes/project-visibility.server.ts:28-44`) — and **P13-D-8** (every authority
refusal writes a `project.authority.denied` audit row, deduped 60 s per
actor+project+action, `project-authority.server.ts:208-230`).

The role→action matrix under test (`rbac.ts:61-88`): `view`/`comment` = all four roles
(enforcement IS the membership gate); `create-task`/`own-task` = A M C;
`approve-transition`/`resolve-packet`/`accept-completion`/`update-goal`/`run-agents`
(and 4 more) = A M; `release-any-ownership`/`manage-members`/`manage-agents`/
`edit-policy`/`force-accept-completion` = A.

## Failure signatures (findings)

- Any action succeeding for a role outside its `ACTION_ROLES` row (esp. viewer
  create-task/own-task, contributor transition/update-goal, maintainer manage-members)
  → **NEW HIGH**: enforcement drift from the single source.
- Non-member gets **403** (not 404) or a different 404 body on the probe project →
  **NEW HIGH**: R15-4 existence leak.
- Probe project appears in Elif/Deniz home grid, ⌘K results, or notifications →
  **NEW HIGH**: R15-4 leak via a secondary surface.
- Missing `project.authority.denied` row for a refusal (outside the 60 s dedup window)
  → **NEW MED** (P13-D-8/NFR10).
- Policy page's rendered matrix disagrees with observed enforcement → **NEW HIGH**
  (the "display and enforcement can never drift" invariant broke).
- Viewer comment refused → **NEW MED** (comment is deliberately role-free within
  membership; compare `timeline.tsx:370` copy "Every project member can comment").
- Elif password reset refused though her account is `credential` → **NEW MED**
  (org user management).
